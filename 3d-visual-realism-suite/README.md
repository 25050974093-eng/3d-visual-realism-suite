# 3D Visual Realism Suite - Grafika Komputer (Minggu 11)

Proyek Java 17 + LWJGL 3.3.1 + JOML + Modern OpenGL (GLSL Shaders 330 core) untuk memenuhi Tugas Mandiri Modul Minggu ke-11.

## Fitur & Tombol Kontrol Interaktif (Saat Aplikasi Berjalan)
- **Key 'B'**: Beralih antara **Phong Shading** dan **Blinn-Phong Shading** (Indikator 1).
- **Key 'F'**: Beralih antara **Flat Shading** dan **Smooth Shading** (Indikator 2).
- **Key 'Z'**: Mengaktifkan/menonaktifkan **Z-Buffer Depth Test** (Indikator 3).
- **Key 'C'**: Mengaktifkan/menonaktifkan **Back-Face Culling** (Indikator 3).

## Cara Menjalankan di VS Code
1. Ekstrak folder ini ke komputer Anda.
2. Buka folder ini di **VS Code** (`File > Open Folder...`).
3. Pastikan ekstensi **Extension Pack for Java** (oleh Microsoft) sudah terpasang.
4. Buka berkas `src/main/java/com/grafkom/viewing3d/Main.java`.
5. Tekan tombol **F5** pada keyboard atau klik tulisan **Run** di atas metode `main`.
